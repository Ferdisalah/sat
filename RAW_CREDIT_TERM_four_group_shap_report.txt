IMPORTANT CAVEATS
1. This report describes the raw predictors + CREDIT_TERM model only.
2. The 0.50 threshold is a diagnostic convention, not necessarily an optimal or calibrated threshold.
3. Positive SHAP pushes toward default; negative SHAP pushes toward non-default.
   SHAP does not establish causality.
4. Each applicant's prediction and SHAP values come from the outer-fold model that did not
   train on that applicant.
5. Missing-value counterfactuals replace one missing feature at a time with the fold-training
   median/mode. This is model sensitivity, not a causal effect.
6. Explicit missing split counts include only numeric FloatFeature splits with an extreme
   negative border. Categorical missing values are encoded as __MISSING__ and analyzed via
   SHAP/counterfactuals, not counted as numeric NaN split rules.
7. The missing-branch traversal count is an exposure count: each validation applicant traverses
   each split level in a symmetric CatBoost tree. It is not a sum of split-level causal effects.
8. This run reports the class imbalance and uses scale_pos_weight=3.37. It does not isolate
   the causal effect of class weighting on learned rules; that requires a separate same-feature-set
   control run with a different weight (for example scale_pos_weight=1.0).
